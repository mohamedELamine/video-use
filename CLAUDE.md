# video-use

## Agent skills

### Issue tracker

Issues live in the fork's GitHub Issues (`mohamedELamine/video-use`), managed with the `gh` CLI — **not** in `origin`, which is the read-only upstream `browser-use/video-use`. See `docs/agents/issue-tracker.md`.

### `skills/wp-reels/` is a historical spike

Preserved research material, **not** the target architecture. Its `reel.json` → HyperFrames pipeline is superseded: Remotion is the composition and final-assembly foundation, HyperFrames a specialised motion engine for individual shots, `video-spec.json` the renderer-agnostic keystone. Its findings migrate selectively; its shape does not. See the banner at the top of `skills/wp-reels/SKILL.md`.

This repo builds a **general** product-video director for arbitrary WordPress themes and SaaS products. Sooq Pro is validation evidence, never an architectural template.
