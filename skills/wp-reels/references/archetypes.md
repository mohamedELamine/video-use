# Reel archetypes

Beat structures for the reels a theme seller needs. Each beat maps to one scene
template. Durations are worked examples for a 15–20s vertical reel; the
voiceover's phrase windows (`vo_phrases.py` or `takes_packed.md`) override them.

## Launch reel — "here is the theme"

| Beat      | Template        | Typical length | What it carries                                        |
| --------- | --------------- | -------------- | ------------------------------------------------------ |
| HOOK      | hook            | 2.5–3.5s       | promise in one line, brand eyebrow, no UI yet          |
| TOUR      | device-scroll   | 5–7s           | full-page capture of the home page scrolling in a card |
| PROOF     | feature-zoom ×1–2 | 3.5–5s each  | one screenshot per feature, punch-in on the payoff     |
| CTA       | cta             | 3–4s           | logo, one-line ask, one button                         |

## Feature reel — "one thing, deeply"

| Beat      | Template        | Typical length | What it carries                                        |
| --------- | --------------- | -------------- | ------------------------------------------------------ |
| PROBLEM   | hook            | 2.5–3s         | the pain, phrased as a question                        |
| FEATURE   | feature-zoom    | 4–6s           | the state screenshot (hover/click capture), ring on it |
| BENEFIT   | device-scroll or feature-zoom | 3–5s | the outcome page (cart, checkout, dark mode …)   |
| CTA       | cta             | 3s             | same CTA as the launch reel, keeps the series coherent |

## Comparison reel — "before / after" (phase 2)

Needs a two-card scene template that is not written yet. Until then, cut two
feature-zoom scenes back to back with the callouts "قبل" / "بعد".

## Rules that hold across archetypes

- One idea per scene. A scene with two callouts is two scenes.
- Callouts are ≤ 4 words; the accent half is the payoff word.
- The CTA scene is identical across every reel of the same theme.
- Total length: 12–20s. Reels past 20s need a second hook mid-way.
